---
title: Eliminate Infrastructure with Pear CLI & Bare JS Runtime
speaker: David Mark Clements
speakerId: david-mark-clements
---

Use Pear CLI and a module to deploy peer-to-peer over-the-air updates to
terminal, desktop, and mobile applications.

Then use Bare, the zero-core JS runtime, to embed the same P2P-capable local
backend in terminal, desktop, and mobile applications — a write-once,
run-anywhere RPC application sidecar.
