Guy works on the Workers runtime at Cloudflare. A long-time Node.js
collaborator, he did much of the work behind the ES modules implementation in
Node.js, and is the author of SystemJS and a co-author of jspm — a decade of
pushing on the unglamorous problem of how JavaScript modules actually load.

His current focus is the boundary between WebAssembly toolchains and JavaScript
runtimes: what it takes to run code that was never written with an event loop
in mind.
